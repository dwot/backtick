## Features

- Zero dependencies
- Works with **any** framework
- Ships as a single `.js` file

+++ card
Start each line with `-`, `*` or `+` followed by a space:

```md
- First thing
- Second thing
```

Items can contain any inline formatting: bold, code, links.

+++ learn
Pick one marker and stick with it. **Switching markers starts a new list**: a `-` item followed by a `*` item gives you two separate lists.

`-` is the most common choice in READMEs.

+++ sheet
- An item
- Another, with `code`

+++ tip
`-`, `*` and `+` all work.
