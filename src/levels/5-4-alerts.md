+++ card
A GitHub extra: a blockquote whose first line is `[!TYPE]` becomes a colored alert box:

```md
> [!TIP]
> Helpful advice.
```

The five types are `NOTE`, `TIP`, `IMPORTANT`, `WARNING` and `CAUTION`. Separate two alerts with a blank line.

+++ learn
Alerts are GitHub-only. Other renderers show a plain quote that starts with "[!NOTE]", which still reads fine.

Use them sparingly. One `WARNING` stands out, but five in a row just get skimmed.
