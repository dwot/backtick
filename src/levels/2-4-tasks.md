+++ card
A GitHub extra: start a bullet item with `[ ]` or `[x]` to make a checkbox:

```md
- [x] Done
- [ ] Not yet
```

The space inside `[ ]` is required.

+++ learn
On GitHub, task lists in issues and pull requests are **clickable**, and an issue shows its progress ("2 of 4 tasks") in lists and search.

They nest like any other list.
